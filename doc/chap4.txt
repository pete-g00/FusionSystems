  [1X4.1 [33X[0;0YBrief description of the algorithm[133X[101X
  
  [33X[0;0YLet  [23XS[123X  be  a finite [23Xp[123X-group. Recall that [23XE[123X is proto-essential in [23XS[123X if there
  [13Xcould[113X  exist  a  saturated  fusion  system  [23X\mathcal{F}[123X on [23XS[123X such that [23XE \in
  \mathcal{E}(\mathcal{F})[123X.             See            Chapter            <Ref
  Chap="Chapter_ProtoEssentialChecks"  />  for  the  list  of  specific  tests
  currently  implemented.  In  this  section,  we  describe  the algorithm for
  constructing  all  the  proto-essential  subgroups  of  [23XS[123X.  This is based on
  [Gau26, Section 3]. We fix a central series of [23XS[123X:[133X
  
  
  [24X[33X[0;6Y1 = Z_0 \leq Z_1 \leq \dots \leq Z_n = S,[133X
  
  [124X
  
  [33X[0;0Ywhere [23X|Z_i| = p^i[123X for [23X1 \leq i \leq n[123X, and there exists some [23X1 \leq j \leq n[123X
  such  that  [23XZ_j  = S'[123X. For [23X0 \leq i < j[123X, let [23X\pi_i \colon S \to S/Z_i[123X be the
  projection map, and[133X
  
  
  [24X[33X[0;6Y\mathfrak{C}_i  :=  \{E  \mid  E = \pi^{-1}(C_S(x)), x \in S/Z_i \textrm{ of
  order } p \textrm{ with } E \textrm{ proto-essential in } S\}.[133X
  
  [124X
  
  [33X[0;0YWe  let  [23X\mathfrak{C}  := \bigcup_{i=0}^j \mathfrak{C}_i[123X. In [Gau26, Theorem
  3.6],  Gautam  shows  that  if [23X\mathcal{F}[123X is a saturated fusion system on [23XS[123X
  with [23XE \in \mathcal{E}(\mathcal{F})[123X, then [23XE[123X is [23X\mathcal{F}[123X-conjugate to some
  [23XX \in \mathfrak{C}[123X.[133X
  
  
  [1X4.2 [33X[0;0YThe operations[133X[101X
  
  [1X4.2-1 AllProtoEssentials[101X
  
  [33X[1;0Y[29X[2XAllProtoEssentials[102X( [3XS[103X ) [32X attribute[133X
  [6XReturns:[106X  [33X[0;10Ya list[133X
  
  [33X[0;0YThe attribute [10XAllProtoEssentials[110X constructs all proto-essential subgroups of
  a [23Xp[123X-group [23XS[123X. It works as follows:[133X
  
  [30X    [33X[0;6Yit  calls  the  function  [10XAllProtoEssentials[110X  which constructs the set
        [23X\mathfrak{C}[123X;[133X
  
  [30X    [33X[0;6Yit  then  calls  [10XGenerateProtoEssentials[110X,  which  uses [23X\mathfrak{C}[123X to
        construct    all    proto-essential    subgroups,    switching    from
        [23X\mathcal{F}[123X-conjugacy to [23XS[123X-conjugacy (independent of [23X\mathcal{F}[123X).[133X
  
  [33X[0;0YIt   should   be   pointed   out   that   there  is  no  known  cases  where
  [10XGenerateProtoEssentials[110X   generates   a   further   ([23XS[123X-conjugacy)  class  of
  proto-essential  subgroups. Finds all the proto-essential subgroups of [23XS[123X, up
  to [23XS[123X-conjugacy.[133X

  [1X4.2-2 MainProtoEssentials[101X
  
  [33X[1;0Y[29X[2XMainProtoEssentials[102X( [3XS[103X[, [3Xi[103X] ) [32X function[133X
  [6XReturns:[106X  [33X[0;10Ya list[133X
  
  [33X[0;0YReturns   the   list   of   the  [10Xmain[110X  proto-essential  subgroups  of  [23XS[123X.  A
  proto-essential subgroup is called [13Xmain[113X if it lies in [23X\mathfrak{C}[123X.[133X
  
  [33X[0;0YIf the second argument [10Xi[110X is provided, the function behaves as follows:[133X
  
  [30X    [33X[0;6Y[23Xi = 0[123X -- we only compute [23X\mathfrak{C}_0[123X;[133X
  
  [30X    [33X[0;6Y[23Xi = -1[123X -- we only compute [23X\mathfrak{C} \setminus \mathfrak{C}_0[123X; and[133X
  
  [30X    [33X[0;6Y[23Xi = 1[123X -- we compute all [23X\mathfrak{C}[123X.[133X
  
  [33X[0;0YIf  the  argument  is  not  provided,  we  compute all [23X\mathfrak{C}[123X. Running
  [10XGenerateProtoEssentials[110Xon   the   list   [23XL[123X   returned   generates   all  the
  proto-essentials subgroups of [23XS[123X.[133X
