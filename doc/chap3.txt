  
  [1X3 [33X[0;0YChecks for proto-essentials[133X[101X
  
  [33X[0;0YIn this chapter, we describe all the tests currently implemented in GAP that
  test  whether  a subgroup [23XE[123X of a [23Xp[123X-group [23XS[123X is proto-essential. Recall that [23XE[123X
  is  proto-essential  in  [23XS[123X  if  there  [13Xcould[113X exist a saturated fusion system
  [23X\mathcal{F}[123X on [23XS[123X such that [23XE \in \mathcal{E}(\mathcal{F})[123X.[133X
  
  
  [1X3.1 [33X[0;0YThe main functions[133X[101X
  
  [1X3.1-1 IsProtoEssential[101X
  
  [33X[1;0Y[29X[2XIsProtoEssential[102X( [3XS[103X, [3XE[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10Ytrue or false[133X
  
  [33X[0;0YLet  [23XS[123X be a [23Xp[123X-group and [23XE[123X be a subgroup of [23XS[123X. The operation [10XIsProtoEssential[110X
  checks whether [23XE[123X is a proto-essential subgroup of [23XS[123X.[133X
  
  [33X[0;0YThis  function  checks whether the group [23XE[123X satisfies certain properties with
  respect  to [23XS[123X that are known to hold when [23XE[123X is an essential subgroup in some
  fusion system [23X\mathcal{F}[123X on [23XE[123X. In this process, we construct (in order):[133X
  
  [30X    [33X[0;6Y[23XC_S(E)[123X;[133X
  
  [30X    [33X[0;6Y[23XN_S(E)[123X;[133X
  
  [30X    [33X[0;6Y[23X\mathrm{Aut}(N_S(E))[123X; and[133X
  
  [30X    [33X[0;6Y[23X\mathrm{Aut}(E)[123X.[133X
  
  [33X[0;0YEach  computation  is  considered  more expensive than the previous one. See
  Section  <Ref  Label="Section_PEChecks"/>  for  the  list of tests currently
  implemented.[133X
  
  [33X[0;0YNote  that  it is possible that [23XE[123X is found to be proto-essential even though
  there    is    no    fusion   system   [23X\mathcal{F}[123X   on   [23XS[123X   with   [23XE   \in
  \mathcal{E}(\mathcal{F})[123X.  This  can  be for various reasons, for example, [23XE[123X
  could be essential in [23X\mathcal{F}[123X only if there is an overgroup of [23XE[123X that is
  also essential, but there is no such group. Some of these cases may be ruled
  out  using  automizer  sequences,  but it cannot be fully determined without
  constructing the actual fusion systems.[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27XS := SmallGroup(3^4, 7);[127X[104X
    [4X[28X<pc group of size 81 with 4 generators>[128X[104X
    [4X[25Xgap>[125X [27XC := SubgroupsSolvableGroup(S);;[127X[104X
    [4X[25Xgap>[125X [27XC := Filtered(C, A -> IsProtoEssential(S, A));[127X[104X
    [4X[28X[ Group([ f3, f4, f1 ]), Group([ f1, f4 ]), Group([ f3, f4, f2 ]) ][128X[104X
    [4X[25Xgap>[125X [27XList(C, StructureDescription);[127X[104X
    [4X[28X[ "(C3 x C3) : C3", "C3 x C3", "C3 x C3 x C3" ][128X[104X

  [1X3.1-2 IsProtoEssentialNC[101X

  [6XReturns:[106X  [33X[0;10Ytrue or false[133X
  
  [33X[0;0YThe  operation [10XIsProtoEssentialNC[110X behaves like [10XIsProtoEssential[110X, but further
  assumes that:[133X
  
  [30X    [33X[0;6Y[23XE[123X is a proper subgroup of [23XS[123X;[133X
  
  [30X    [33X[0;6Y[23XC_S(E) \leq E[123X;[133X
  
  [30X    [33X[0;6Y[23XE[123X passes [10XZed0Test[110X.[133X
  
  
  [1X3.2 [33X[0;0YThe specific functions[133X[101X
  
  [1X3.2-1 Zed0[101X
  
  [33X[1;0Y[29X[2XZed0[102X( [3XS[103X ) [32X attribute[133X
  [6XReturns:[106X  [33X[0;10Ya subgroup[133X
  
  [33X[0;0YLet  [23XS[123X be a [23Xp[123X-group. The function [10XZed0[110X computes the subgroup [23XZ_0[123X of [23XS[123X, which
  is given by:[133X
  
  
  [24X[33X[0;6YZ_0 := \langle x \in Z_2(S) \mid |[S, x]| \leq p \rangle.[133X
  
  [124X
  
  [33X[0;0YLet  [23XS[123X  be  a [23Xp[123X-group and [23XE[123X be a subgroup of [23XS[123X. The function [10XZed0Test[110X checks
  that one of the following holds:[133X
  
  [30X    [33X[0;6Y[23XZ_0 \leq E[123X; or[133X
  
  [30X    [33X[0;6Y[23X[N_S(E) : E] = p[123X, and there exists some [23Xx \in \Omega(Z(E))[123X such that [23XE
        = C_S(x)[123X.[133X
  
  [33X[0;0YNote  that  this  function is not used when constructing [23X\mathfrak{C}[123X as the
  choice  of  [23Xx[123X  is  easier  to  find  while  the  set [23X\mathfrak{C}_0[123X is being
  constructed.  This  test  applies  at  any  prime  [23Xp[123X. It is based on [AOV17,
  Proposition 2.3(a)] (proven for [23Xp=2[123X).[133X

  [1X3.2-3 RankTest[101X
  
  [33X[1;0Y[29X[2XRankTest[102X( [3XS[103X, [3XE[103X ) [32X operation[133X
  [6XReturns:[106X  [33X[0;10Ya number[133X
  
  [33X[0;0YLet  [23XS[123X  be  a [23Xp[123X-group and [23XE[123X be a subgroup of [23XS[123X. The function [10XRankTest[110X checks
  that  [23X\textrm{Out}_S(E)[123X  is  isomorphic  to  a  Sylow  [23Xp[123X-subgroup of a group
  containing  a  strongly  [23Xp[123X-embedded  subgroup.  If  so,  we  return  a value
  specifying its type, namely:[133X
  
  [30X    [33X[0;6Y[23X0[123X -- [23X\textrm{Out}_S(E)[123X is cyclic or quaternion;[133X
  
  [30X    [33X[0;6Y[23X1[123X -- [23X\textrm{Out}_S(E)[123X is elementary abelian of order [23X\geq p^2[123X;[133X
  
  [30X    [33X[0;6Y[23X2[123X -- Sylow [23Xp[123X-subgroup of [23X\textrm{PSU}_3(p^n)[123X;[133X
  
  [30X    [33X[0;6Y[23X3[123X -- Sylow [23X2[123X-subgroup of [23X\mathrm{Sz}(2^{2n+1})[123X;[133X
  
  [30X    [33X[0;6Y[23X4[123X -- Sylow [23X3[123X-subgroup of [23X{^2\mathrm{G}}_2(3^{2n+1})[123X; and[133X
  
  [30X    [33X[0;6Y[23X5[123X -- [23X3^{1+2}_-[123X and [23X5^{1+2}_-[123X.[133X
  
  [33X[0;0YWe  return  [23X-1[123X  none  of  the cases above apply. During the process, we also

  [33X[0;0YThis test applies at any prime [23Xp[123X. It is based on [Sam14, Proposition 6.9].[133X
  
  [4X[32X  Example  [32X[104X

    [4X[28XGroup([ f2, f3, f4, f5, f6 ])[128X[104X
