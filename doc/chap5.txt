  [33X[0;0YIn this chapter, we describe all the tests currently implemented in GAP that
  test  whether  a  group [23XS[123X [13Xcould[113X support reduced fusion systems. This is done
  without  constructing  the  fusion systems, and even possible automizers for
  any  fusion  system.  As  such,  we  can  determine whether there exists any
  reduced   fusion   system   [23X\mathcal{F}[123X   on   [23XS[123X   for  a  fixed  choice  of
  [23X\mathcal{E}(\mathcal{F})[123X.  We  can  also  determine  this  for any choice of
  [23X\mathcal{E}(\mathcal{F})[123X.[133X
  
  
  [1X5.1 [33X[0;0YThe main functions[133X[101X
