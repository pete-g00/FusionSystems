6 Other functions

6.1 Group actions

6.1-1 OnQuotient
‣ OnQuotient( q )( function )

Returns: a function

Let G be a finite group, and A be a normal subgroup of G. Let q \colon G \to G/A. The function OnQuotient(q) returns a function, such that for t \in G/A and x \in G, OnQuotient(q)(t, x) returns q(x^{-1}hx), where h \in G satisfies q(h) = t.

6.1-2 CentralizerMod
‣ CentralizerMod( G, A, B )( operation )

Returns: a subgroup of G

Let G be a finite group, with subgroups B \leq A \leq G, where B is normal in G. The operation CentralizerMod(G, A, B) returns the subgroup C_G(A/B), given by:

C_G(A/B) := \langle x \in G \mid [A, x] \leq B \rangle.

gap> S := SmallGroup(5^6, 643);
<pc group of size 15625 with 6 generators>
gap> U := UpperCentralSeries(S);
[ Group([ a6, a5, a4, a3, a1, a2 ]), Group([ a6, a5, a4, a3 ]), 
Group([ a6, a5, a4 ]), Group([ a6, a5 ]), Group([ a6 ]), Group([  ]) ]
gap> R := CentralizerMod(S, U[4], U[6]);
Group([ <identity> of ..., a2, a3, a4, a5, a6 ])
gap> R = Centralizer(S, U[4]);
true
gap> A := CentralizerMod(S, U[3], U[5]);
Group([ a1, <identity> of ..., a3, a4, a5, a6 ])
gap> A = R;
false

6.1-3 OnImage
‣ OnImage( x, phi )( function )

Returns: an element or a subset

Let \phi be a map and let x be either an element or a subset of the domain of \phi. The function OnImage(x, phi) returns \phi(x).

6.1-4 OnImageNM
‣ OnImageNM( n )( function )

Returns: a function

Let G be a group and n a nice monomorphism for (a subgroup of) \mathrm{Aut}(G), with image A. The function OnImageNM(n) returns a function such that, for some element \phi \in A and an element (or a subgroup) x of G, OnImageNM(n)(x, phi) return \hat{\phi}(x), where \hat{\phi} \in \mathrm{Aut}(G) is the preimage of \phi with respect to the injective map n.

gap> S := SmallGroup(5^6, 642);
<pc group of size 15625 with 6 generators>
gap> AutS := AutomorphismGroup(S);
<group of size 1562500 with 10 generators>
gap> n := NiceMonomorphism(AutS);
<action isomorphism>
gap> AutS := n(AutS);
<permutation group of size 1562500 with 10 generators>
gap> V := Group(S.2, S.6);
<pc group with 2 generators>
gap> A := Stabilizer(AutS, V, OnImageNM(n));
<permutation group of size 12500 with 7 generators>

6.1-5 OnImageTuples
‣ OnImageTuples( L, phi )( function )

Returns: a list

Let \phi be a map and let L be a list of elements in the domain of \phi. The function OnImageTuples(L, phi) returns a list containing \phi(x) for each x \in L, while maintaining the order.

6.1-6 OnImageTuplesNM
‣ OnImageTuplesNM( n )( function )

Returns: a function

Let G be a group and n a nice monomorphism for (a subgroup of) \mathrm{Aut}(G), with image A. The function OnImageTuplesNM(n) returns a function such that, for some element \phi \in A and a list L of elements in G, OnImageTuplesNM(n)(L, phi) return a list of elements \hat{\phi}(x), where x \in L and \hat{\phi} \in \mathrm{Aut}(G) is the preimage of \phi with respect to the injective map n.

6.1-7 OnPreImage
‣ OnPreImage( q )( function )

Returns: a function

Let A be a group that acts on the set \Omega with kernel K, and let q \colon A \to G be a group homomorphism with \ker(q) \leq K. The function OnPreImage(q) returns a function, such that, for some element g \in G and x \in \Omega, OnPreImage(q)(x, g) returns x^a, where a \in A is the preimage of g with respect to q.

6.1-8 OnPreImageTuples
‣ OnPreImageTuples( q )( function )

Returns: a function

Let A be a group that acts on the set \Omega with kernel K, and let q \colon A \to G be a group homomorphism with \ker(q) \leq K. The function OnPreImageTuples(q) returns a function, such that, for some element g \in G and a subset L \subseteq \Omega, OnPreImageTuples(q)(L, g) returns a list consisting of x^a for x \in L, where a \in A is the preimage of g with respect to q.

6.2 Group automorphisms

6.2-1 Automizer
‣ Automizer( G, H )( operation )
‣ Automizer( A, H )( operation )

Returns: a subgroup of Aut(H)

Let G and H be subgroups of some finite group. The group Automizer(G, H) is the automizer subgroup \mathrm{Aut}_G(H), given by:

\mathrm{Aut}_G(H) := \langle c_g \mid g \in N_G(H) \rangle,

where c_g \colon H \to H is the conjugation automorphism. It is a subgroup of \mathrm{Aut}(H).

gap> G := AlternatingGroup(6);
Alt( [ 1 .. 6 ] )
gap> S := SylowSubgroup(G, 2);
Group([ (1,2)(3,4), (1,3)(2,4), (1,2)(5,6) ])
gap> M := MaximalSubgroups(S);
[ Group([ (3,4)(5,6), (1,2)(3,4) ]), Group([ (1,3)(2,4), (1,2)(3,4) ]), 
Group([ (1,3,2,4)(5,6), (1,2)(3,4) ]) ]
gap> AutGM := List(M, A -> Automizer(G, A));
[ <group with 2 generators>, <group with 2 generators>, 
<group with 2 generators> ]
gap> List(AutGM, StructureDescription);
[ "S3", "S3", "C2" ]

Alternatively, if A is a subgroup of \mathrm{Aut}(G), then Automizer(A, H) returns the subgroup \mathrm{Aut}_A(H) of \mathrm{Aut}(H) given by:

\mathrm{Aut}_A(H) := \langle \alpha|_H \mid \alpha \in A, \alpha(H) = H \rangle.

gap> S := SmallGroup(5^6, 642);
<pc group of size 15625 with 6 generators>
gap> V := Group(S.2, S.6);
<pc group with 2 generators>
gap> AutS := AutomorphismGroup(S);
<group of size 1562500 with 10 generators>
gap> AutSV := Automizer(AutS, V);
<group with 7 generators>
gap> AutV := AutomorphismGroup(V);;
gap> n := NiceMonomorphism(AutV);
<action isomorphism>
gap> AutV := n(AutV);;
gap> Size(AutV);
480
gap> AutSV := n(AutSV);
<permutation group with 7 generators>
gap> Index(AutV, AutSV);
24
gap> Size(AutSV);
20

6.2-2 Restriction of homomorphisms
‣ RestrictedHomomorphismOnto( phi, X )( operation )
‣ RestrictedAutomorphism( phi, X )( operation )

Returns: a group automorphism

Let \phi \colon A \to B be a group homomorphism, and let X \leq A. The operation RestrictedHomomorphismOnto(phi, X) returns the surjective group homomorphism \phi|_X \colon X \to \phi(X) given by restriction. If \phi is also an isomorphism that fixes X, then the operation RestrictedAutomorphism(phi, X) returns the group automorphism \phi|_X \colon X \to \phi(X) given by restriction.

6.2-3 Transfer homomorphism
‣ TransferHomomorphism( G, S )( operation )
‣ TransferHomomorphismFp( G, S )( operation )

Returns: a homomorphism

Let G be a finite group and S \leq G. The operation TransferHomomorphism(G, S) returns the transfer homomorphism \mathrm{tr}_S^G \colon G \to S/S'. Moreover, if S is a p-group, then the operation TransferHomomorphismFp(G, S) returns the transfer homomorphism \mathrm{tr'}_S^G \colon G \to S/\Phi(S).

6.3 Semi-characteristic subgroups

Let S be a p-group and A \leq S. We say that A is semi-characteristic in S if

  • A is normal in S, and

  • A is fixed by O^p(O^{p'}(\mathrm{Aut}(S))).

6.3-1 SemiAutomorphismGroup
‣ SemiAutomorphismGroup( S )( attribute )

Returns: a subgroup of Aut(S)

Let S be a p-group. The operation SemiAutomorphismGroup returns the semi-automorphism group of S, which is given by \langle \mathrm{Inn}(S), O^p(O^{p'}(\mathrm{Aut}(S)))\rangle.

6.3-2 SemiCharacteristicSubgroups
‣ SemiCharacteristicSubgroups( S )( attribute )

Returns: a list

Let S be a p-group. The attribute SemiCharacteristicSubgroups returns all the semi-characteristic subgroups of S. These are the normal subgroups of S fixed by O^p(O^{p'}(\mathrm{Aut}(S))).

6.3-3 IsSemiCharacteristic
‣ IsSemiCharacteristic( S, A )( operation )

Returns: true or false

Let S be a p-group and A be a subgroup of S. The operation IsSemiCharacteristic checks whether A is semi-characteristic in S. That is, we check whether:

  • A is normal in S, and

  • A is fixed by O^p(O^{p'}(\mathrm{Aut}(S))).

6.3-4 SemiCharacteristicClosure
‣ SemiCharacteristicClosure( S, A )( operation )

Returns: a subgroup of S

Let S be a p-group and A be a subgroup of S. The operation SemiCharacteristicClosure returns the smallest semi-characteristic subgroup of S containing A. This is the intersection of all semi-characteristic subgroups of S containing A.

gap> S := SmallGroup(2^8, 6331);
<pc group of size 256 with 8 generators>
gap> E1 := Group(S.1, S.2, S.4, S.5, S.6, S.7, S.8);
<pc group with 7 generators>
gap> E2 := Group(S.1, S.2, S.4, S.5, S.7, S.8);
<pc group with 6 generators>
gap> A := Group(S.5*S.8);
<pc group with 1 generator>
gap> AutomorphismGroup(E1);
<group of size 6144 with 12 generators>
gap> AutomorphismGroup(E2);
<group of size 12288 with 13 generators>
gap> IsCharacteristicSubgroup(E1, A);
false
gap> IsCharacteristicSubgroup(E2, A);
false
gap> IsPGroup(E1);
true
gap> IsPGroup(E2);
true
gap> SemiAutomorphismGroup(E1);
<group of size 384 with 8 generators>
gap> SemiAutomorphismGroup(E2);
<group of size 3072 with 11 generators>
gap> IsPGroup(A);
true
gap> IsSemiCharacteristic(E1, A);
true
gap> IsSemiCharacteristic(E2, A);
false
gap> SemiCharacteristicClosure(E2, A);
Group([ f4, f5, f8, f4*f5, f4*f8, f5*f8, f4*f5*f8 ])
